# TraceOSCE 管理端 v2 设计文档

## 目标

在不改动现有管理端首页 `/` 的前提下，新增一套独立的管理端 v2 入口 `/v2`。v2 采用 shadcn/ui Dashboard Blocks 的布局思想：左侧资源导航、顶部操作栏、核心指标卡、主表格、右侧或弹窗详情面板。目标是把当前“所有模块堆在一个长页面里”的管理后台，重组为更接近标准管理系统的工作台。

本次改造不是替换旧管理端，也不删除旧功能。旧版继续保留作为调试与兼容入口；v2 先作为新的演示和答辩入口。

## 当前管理端功能盘点

### 配置与运行状态

- 服务端默认模型能力。
- 模型 API 调用日志。
- RAG 检索、Chroma 和 embedding 状态。
- RAG 召回评测。
- 运行边界说明。

### 教学资源

- 病例台账。
- Rubric 评分表。
- 来源台账。
- RAG 知识库条目。
- 文档知识库上传、启用、停用。
- 高级手工知识条目录入。
- 病例 JSON 校验和导入。

### 训练管理

- 训练 Session 列表。
- Session 详情。
- 评分报告读取。
- 训练事件日志。
- Agent 轨迹。
- Skill 跳过原因。
- AI 模拟查体 / 检查审计。

### 教学洞察

- 高频漏项。
- 错误模式统计。
- 教学重点。
- 来源引用热度。

### Skill 进化

- 从训练日志生成候选 Skill。
- 候选 Skill 列表和详情。
- 回归门禁结果。
- 审批 Agent 修订记录。
- 管理员批准 / 拒绝。
- 自动应用开关。
- Skill 效果统计。
- 审批审计事件。

### 系统评测与审计

- 系统评测批次。
- 评测用例详情。
- 运行评测。
- 当前页 JSON 导出。
- 全部审计事件、Skill 审核事件、管理操作事件。

## 当前问题

1. 所有模块以长页面形式展开，信息层级过平。
2. 主阅读区混入大量技术 ID、内部字段、英文枚举和原始 JSON。
3. 列表、详情、审计、导出和运行操作没有清晰分层。
4. 资源、训练、Skill、评测之间的关系需要通过滚动和二级 Tab 查找，不像标准后台。
5. API 调用日志、模型成功率、最近错误等运维型信息没有独立成清晰看板。

## v2 信息架构

v2 左侧主导航采用 7 个一级模块：

1. 概览
2. 教学资源
3. 训练管理
4. 教学洞察
5. Skill 进化
6. 系统评测
7. 审计日志

每个模块优先采用“数据表 + 详情面板”的后台工作流。主表只展示教师能快速理解的中文业务字段；技术细节、原始 JSON、内部 ID 和审计上下文进入详情面板或折叠区。

## shadcn/ui Dashboard Blocks 采用方式

官方 Dashboard Blocks 是可复制源码块，不是完整后台框架。v2 采用其结构模式，而不是原样使用示例业务数据。

采用的结构：

- Sidebar：左侧模块导航。
- SiteHeader：顶部标题、刷新、登录状态。
- SectionCards：核心指标卡。
- DataTable：主要资源列表。
- Detail panel：选中行后的详情区域。

不直接引入官方 `dashboard-01` 的全部依赖，原因：

- 官方示例带有图表、拖拽表格和英文演示数据，不适合直接进入本项目。
- 当前项目已用 Next.js + Tailwind，v2 可以用轻量组件先落地。
- 旧版管理端必须不受影响，避免 CLI 初始化改写全局样式。

## v2 首版范围

首版 `/v2` 应覆盖可演示的管理闭环：

- 管理员登录 / 登出。
- 系统概览指标：Session、报告、候选 Skill、评测、最近模型调用状态。
- 训练 Session 表格：病例、学生、阶段、更新时间、状态、操作。
- 选中 Session 后显示详情、报告入口和 Skill 跳过原因摘要。
- API 调用日志表格：provider、model、target、状态、耗时、时间。
- 教学资源摘要：病例数、来源数、知识库文档数。
- Skill 摘要：候选、自动应用状态、效果统计样本状态。
- 评测摘要：批次数、通过率、最近批次。
- 保留跳转旧版入口，便于查看尚未迁移的深层调试项。

## 后续增强范围

- 把病例、Rubric、知识库、来源台账拆成资源详情页。
- Skill 候选详情改为抽屉，支持批准 / 拒绝 / 查看审批 Agent 修订。
- 增加模型调用成功率趋势、错误分类和请求耗时分布。
- 增加知识库检索测试入口。
- 增加报告列表和报告详情入口。
- 增加班级 / 学生维度统计，但不伪造样本不足时的效果提升。

## 当前边界

- v2 不删除、不覆盖旧管理端 `/`。
- v2 首版优先解决布局、可读性和关键证据展示，不一次性迁移所有深层调试能力。
- 技术 ID 和原始 JSON 不作为主界面阅读内容，只在详情或旧版入口保留。
- v2 只读取现有后端 API，不改变后端评分、RAG、Skill、审批或评测逻辑。
