# TraceOSCE 管理端 v2 设计文档

## 目标

根路径 `/` 已切换为 v2 工作台，`/v2` 继续保留为兼容入口。v2 采用 shadcn/ui Dashboard Blocks 的布局思想：左侧资源导航、顶部操作栏、核心指标卡、主表格、右侧或弹窗详情面板。目标是把当前“所有模块堆在一个长页面里”的管理后台，重组为更接近标准管理系统的工作台。

本次改造将 v2 设为默认管理端入口；历史长页面不再作为公开默认入口。原本依赖旧页面的调试信息需要迁移到 v2 的详情弹窗、折叠区或后端接口中展示。

## 当前管理端功能盘点

### 配置与运行状态

- 读取服务端已配置的模型能力数量。
- 展示脱敏后的模型 API 调用日志、成功率、错误和耗时。
- RAG 召回评测由管理员按需运行，展示召回指标与运行边界。
- 当前没有 Chroma / embedding 实时健康面板，也不能在管理端修改模型配置。

### 教学资源

- 病例台账。
- Rubric 评分表。
- 来源台账：显示来源版本、最近 / 下次复核日期、当前状态和替代关系；新病例和新知识只允许选择当前有效来源。
- 来源治理：管理员可新增、完整修订、记录医学复核、停用来源，并查看不可覆盖的版本历史、最近差异和回滚；每次动作进入统一审计。
- RAG 知识库条目。
- 文档知识库上传、启用、停用。
- 高级手工知识条目录入。
- 病例工坊：字段化创建教学病例，并在导入前生成配套 Case / Rubric payload 做预检。
- 完整病例版本：高级入口可同时编辑病例全部隐藏事实与完整 Rubric（含维度权重），后端重新验证 Case / Rubric 配对后才原子写入；支持医学审核、差异和回滚。

### 班级与用户

- 管理员可创建学生、教师和管理员账号，修改姓名、邮箱、角色和启用状态，重置密码并注销旧会话，或撤销登录权限但保留历史训练证据。
- 固定演示账号由运行环境托管；当前管理员不能在页面中修改自己的邮箱、角色或启用状态，避免自锁。
- 创建、编辑、归档和删除班级，从启用中的学生账号选择成员，并从启用中的教师账号指定班级负责人。
- 支持中文 / 英文表头 CSV 先校验后原子导入，支持合并或替换同名班级成员；支持在班级间批量复制或移动学生。
- 班级和成员关系保存在 SQLite，重启后可回读；删除班级不删除学生账号与训练记录。
- 教学洞察可按班级成员过滤学情，空班级返回空统计，不会误用全体学生数据。

### 训练管理

- 训练 Session 列表。
- Session 详情。
- 评分报告读取。
- 训练事件日志。
- Agent 轨迹。
- 教师智能体介入轨迹：按轮展示静默、观察、提示、阻断，包含触发原因、可见提示、实际 Skill 调用与资料来源数量。
- Skill 跳过原因。
- 历史 AI 模拟查体 / 检查审计（仅兼容读取旧报告；当前活动训练不再新增）。

### 教学洞察

- 高频漏项。
- 错误模式统计。
- 教学重点。
- 来源引用热度。

### Skill 进化

- 从训练日志生成候选 Skill。
- 候选 Skill 列表和详情。
- 回归门禁结果。
- 审批 Agent 修订记录。
- 管理员批准 / 拒绝。
- 自动应用开关。
- Skill 效果统计。
- 审批审计事件。

### 系统评测与现有日志

- 系统评测批次。
- 评测用例详情。
- 评测场景维护：选择真实训练病例，配置学生操作步骤、期望分数、禁用内容和启用状态。
- 自定义评测套件：组合一个或多个场景，配置分数容差、批次最低通过率、RAG 解释 / 证据覆盖、来源强制门和最长耗时。
- 手动选择套件运行评测；批次记录套件、阈值、触发人和运行时间。
- 定时评测：按 5 分钟至 7 天间隔运行指定套件，计划、下次时间、最近批次和错误持久化；租约防止同一计划并发重复执行，服务重启后继续轮询。
- 按需运行 RAG 检索评测。
- 模型 API 调用日志。
- Skill 审批事件位于“Skill 进化”模块。
- 账号、班级、来源、病例、Rubric、知识库、Skill 与评测动作已进入统一 SQLite 审计台账，记录操作者、动作、对象、前后值和元数据，并可筛选、分页及导出 CSV / JSON。

## 当前问题

1. 所有模块以长页面形式展开，信息层级过平。
2. 主阅读区混入大量技术 ID、内部字段、英文枚举和原始 JSON。
3. 列表、详情、审计、导出和运行操作没有清晰分层。
4. 资源、训练、Skill、评测之间的关系需要通过滚动和二级 Tab 查找，不像标准后台。
5. API 调用日志、模型成功率、最近错误等运维型信息没有独立成清晰看板。

## v2 信息架构

v2 左侧主导航采用 8 个一级模块：

1. 概览
2. 班级管理
3. 教学资源
4. 训练管理
5. 教学洞察
6. Skill 进化
7. 系统评测
8. 审计与调用日志

每个模块优先采用“数据表 + 详情面板”的后台工作流。主表只展示教师能快速理解的中文业务字段；技术细节、原始 JSON、内部 ID 和审计上下文进入详情面板或折叠区。

## shadcn/ui Dashboard Blocks 采用方式

官方 Dashboard Blocks 是可复制源码块，不是完整后台框架。v2 采用其结构模式，而不是原样使用示例业务数据。

采用的结构：

- Sidebar：左侧模块导航。
- SiteHeader：顶部标题、刷新、登录状态。
- SectionCards：核心指标卡。
- DataTable：主要资源列表。
- Detail panel：选中行后的详情区域。

不直接引入官方 `dashboard-01` 的全部依赖，原因：

- 官方示例带有图表、拖拽表格和英文演示数据，不适合直接进入本项目。
- 当前项目已用 Next.js + Tailwind，v2 可以用轻量组件先落地。
- 根路径和 `/v2` 必须保持同一套 v2 入口，避免服务器部署后仍进入旧版长页面。

## v2 首版范围

首版 v2 应覆盖可演示的管理闭环：

- 管理员登录 / 登出。
- 账号管理：创建和维护学生、教师、管理员账号，支持禁用、密码重置、撤销登录权限和角色分配。
- 班级管理：支持创建、改名、负责人、归档、成员调整、CSV 导入和批量调班。
- 系统概览指标：Session、报告、候选 Skill、评测、最近模型调用状态。
- 训练 Session 表格：病例、学生、阶段、更新时间、状态、操作。
- 选中 Session 后显示详情、报告入口、教师智能体介入轨迹和 Skill 跳过原因摘要。
- 历史 AI 模拟审计：只读展示旧版本报告中已有的审核记录；当前活动训练对未配置项目返回 `unavailable`，不再生成新的模拟记录。
- API 调用日志表格：provider、model、target、状态、耗时、时间。
- 教学资源摘要：病例数、来源数、知识库文档数。
- 病例台账：查看病例详情、编辑病例基础信息、查看并编辑 Rubric 评分项说明。
- 来源台账与时效复核：汇总复核有效、到期待复核、未记录复核和已被新来源替代的数量，并提供来源原页链接；界面明确说明项目复核不等于医学教师审定。
- 知识库文档：上传文档，绑定全局 / 病例范围、适用训练阶段和可用 Agent，启用 / 停用文档；支持服务端搜索和分页、整文档删除与逐片段删除。表格显示可检索、待审和已拒绝片段数，支持批量处理待审片段。内容弹窗按文档读取全部分块，展示质量警告、风险标记、准入状态和审核人 / 时间 / 说明，可逐片段编辑、批准、退回或删除。
- 教学资源病例工坊：用基础信息、标准化病人、线索与检查、评分 Rubric 四步字段创建新病例，前端生成结构化 Case / Rubric 后复用现有 `/api/admin/cases/validate` 与 `/api/admin/cases/import`。
- 教学洞察：高频漏项、训练模式和动态教学重点；学情分析可切换为某一班级的真实成员范围。
- Skill 摘要：候选、自动应用状态、效果统计样本状态。
- Skill 详情：完整 Skill 内容、教学策略、适用时机、成功指标、来源报告，以及审批 Agent 的中文结论、修订字段、质量检查、知识依据和回归门结果。
- Skill 审计：显示全局审核审计事件。
- 评测摘要：批次数、通过率、最近批次。
- 系统评测配置：维护评测场景、套件、阈值和定时计划；手动运行时可选择任一启用套件。
- RAG 检索评测：在系统评测页按需运行，展示 Recall、MRR、nDCG、Hit@5、零命中查询、来源覆盖和运行边界；逐条明细会展示口语查询扩展结果。该重任务不再跟随后台首屏刷新，避免重排或模型超时阻塞班级、病例和训练管理。
- 训练与报告中心：Session、报告、候选 Skill 与评测批次均支持服务端搜索和分页；报告可独立打开，并按当前搜索条件导出 CSV / JSON。
- 统一审计：账号、班级、来源、病例、Rubric、知识库、Skill 与评测动作已可按对象搜索、翻页并导出 CSV / JSON；模型调用观测与管理操作审计位于同一一级模块但保持不同日志语义。

## 当前未接线或仅部分生效的管理能力

### 完全未接线

- 模型配置编辑：当前只读取已配置能力和调用日志，没有保存 Provider / Model 配置或连通性测试的管理表单。

### 仅部分生效

- 暂无。除明确只读的模型配置外，当前盘点中的管理动作均已接线；真实部署仍需结合外部模型、浏览器下载策略和数据量做持续验收。

### 已完整接线

- 账号生命周期：创建、角色分配、启用 / 禁用、密码重置、会话注销和软删除均有后端权限校验、SQLite 持久化、管理端操作入口和审计记录。
- 班级高级管理：负责人、归档、CSV 原子导入、成员复制 / 移动均已接通；账号状态变化后会重新读取班级投影，禁用账号不会继续显示为有效成员或负责人。
- 来源全生命周期：新增、完整更新、时效复核、替代关系、停用、版本差异与回滚均有页面、后端校验、持久化版本和审计。
- 病例与 Rubric 全量版本：基础字段编辑、完整 JSON 资产编辑、维度权重、医学审核、差异与回滚均已接通；任一模型或配对校验失败时不会留下半套病例资产。
- 列表与报告：Session、报告、Skill 和评测均已接通后端搜索和分页；报告中心提供独立列表、详情入口和条件化 CSV / JSON 导出。
- 知识库治理：上传、启停、逐片段编辑审核、整文档批量审核、文档搜索分页、文档删除和片段删除均已生效；删除会同步清理检索缓存并进入统一审计。
- Skill 与评测审计：候选生成、自动应用开关、人工批准 / 拒绝，以及评测场景、套件、计划和运行结果均进入统一审计。
- 系统评测治理：场景、套件、阈值、手动选套件运行和持久化定时计划均已接通；默认核心回归仍保留为内置基线，不能删除但可在页面维护。
- 首屏与启动容错：前端 21 类管理资源独立读取，单一接口失败只显示对应模块警告；后端各 SQLite 存储独立初始化并汇总失败项，一个存储故障不会阻止后续存储执行初始化，但 readiness 仍会诚实标记失败。

### 明确为只读，不是故障

- “历史模拟审计”只用于兼容旧报告中已有的模拟记录；当前活动训练不再生成这类记录，因此空列表是预期状态。

## 当前边界

- 根路径 `/` 已切换为 v2 工作台，`/v2` 继续保留为兼容入口。
- v2 优先解决布局、可读性和关键证据展示；深层调试能力保留在结构化弹窗、详情面板或后端接口中。
- 技术 ID 和原始 JSON 不作为主界面阅读内容；统一管理审计可按需导出供追溯。
- v2 的账号、班级与成员 API 不改变后端评分、RAG、Skill、审批或评测逻辑；班级只用于教学组织和统计过滤。
- 学生维度的“长期反复 gap”只在同类缺口跨至少 2 份报告重复，或上游明确标记为 `persistent` 时成立；单次漏项只进入“当前 gap”，不伪装成纵向证据。
- 可执行训练任务同时从临床高频漏项和人文沟通缺口生成，保留触发阶段、学生动作、成功信号与来源次数，并将单个范围的任务限制在 4 条以内。
