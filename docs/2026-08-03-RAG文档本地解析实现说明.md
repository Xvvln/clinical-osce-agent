# RAG 文档本地解析实现说明

## 目标

教师上传教学资料时，不再让 PDF、DOCX、PPTX 和 HTML 的基本解析依赖 Unstructured 的可选格式模块。常见格式先走项目已有的轻量依赖，其他格式仍可使用 Unstructured 兜底。

## 已实现格式

| 格式 | 本地解析器 | 保留信息 |
| --- | --- | --- |
| MD / Markdown | 项目内 Markdown 解析 | 标题、章节、段落 |
| TXT / TEXT / CSV | 项目内文本解析 | 段落 |
| HTML / HTM | 标准库 `HTMLParser` | 标题、正文、列表；忽略脚本和样式 |
| PDF | `pypdf` | 页码、可选择文本、简单章节 |
| DOCX | `python-docx` | 标题、段落、表格文本 |
| PPTX | `python-pptx` | 幻灯片页码、标题、正文、表格文本 |

所有格式继续使用统一的章节窗口切分、长度警告、风险标记和 `source_location` 追溯字段。管理端文件选择器已加入 PPTX。

## 明确边界

- PDF 本地解析只读取可选择文本；扫描版 PDF 若无文本层，会明确提示先做 OCR，不把空内容伪装成已入库。
- 图片型 PPTX、图片内文字、复杂图表语义和高精度版面结构暂不解析。
- 文档解析成功只代表可形成候选知识片段；是否能被 Agent 读取仍受病例、可见性、角色、启用状态和后续阶段范围约束。

## 验证

- 单元测试覆盖 PDF、扫描 PDF 边界、DOCX、PPTX、HTML、Markdown 和 Unstructured 兜底。
- 使用工作区真实文件做只读烟测：文本型 PDF、DOCX、普通 PPTX 均成功生成 chunk；图片型 PPTX 保持“无可读文本”边界。
