# 高级模式首病例：学生完整操作流程

本文档用于完整模拟一名真实医学生使用 TraceOSCE 完成一次训练。主病例为病例库第一个病例“右下腹痛教学病例”（`appendicitis_001`），训练模式选择“高级”。

这不是满分答案背诵稿。脚本覆盖最重要的问诊、查体、检查、鉴别、沟通和人文要点，同时保留少量合理遗漏，让教师智能体在报告中能指出真实问题、给出下一轮可执行的训练建议。

> 演示人员注意：下文“预期获得的信息”用于核对系统，不要在患者回答前念给学生，也不要提前粘贴到聊天框。

## 一、本轮演示要达到什么效果

完成后，观看者应该能够清楚看到：

1. 学生不是直接猜诊断，而是通过多轮问诊逐步形成临床判断。
2. 标准化患者只按当前病例作答，每一次患者回复都显示情绪标签，并提供语音播放按钮。
3. 高级模式下，学生要用自然语言自行申请查体和辅助检查，系统不会把全部项目直接摆出来供其点选。
4. 教师智能体在训练中给“下一步怎么想”的过程提示，但不直接透露标准诊断。
5. 学生需要在最终表单中分别填写主诊断、鉴别诊断、支持证据、排除依据、下一步计划和不确定点。
6. 训练结束后，教师智能体不仅给分，还要解释证据链在哪里完整、哪里断裂，以及下一轮具体怎么练。

本轮建议用时 15～20 分钟，不建议为了录屏把所有问题压缩成一两句话。

## 二、进入病例和训练模式

### 1. 登录并进入病例库

1. 使用学生账号登录学生端。
2. 点击“病例库”。
3. 找到第一个病例“右下腹痛教学病例”。
4. 在病例卡的“选择训练难度”中选择“高级”。
5. 确认下方说明显示高级模式，再点击“进入工作台”。

病例卡本身标注的“初级”是病例内容难度；这里选择的“高级”是训练交互模式。两者不冲突。进入高级模式后，查体和检查均由学生自由输入申请。

### 2. 进入工作台后先确认页面

学生此时只能看到患者基本信息、主诉和训练任务，不应看到隐藏事实、标准诊断或评分量表。

开始前确认页面上有：

- 中间的问诊对话区和“发送问诊”按钮；
- “请求提示”和“患者信息”按钮；
- 高级模式专用的“输入想申请的查体或检查”“提交申请”“查看申请内容”；
- 右侧“提交诊断与推理”；
- 右侧“已收集线索”等过程面板。

## 三、多轮问诊：像真实学生一样逐步收集信息

不要一次把十几个问题堆进同一条消息。下面按真实接诊节奏分为五轮病史采集；后续还会分别完成查体前沟通、检查前沟通和结果解释。每轮都要等待患者回答后再继续。

### 第 1 轮：自我介绍、说明目的、开放式开场

在问诊输入框填写：

```text
您好，我是今天接诊的实习医生，想先了解这次腹痛的经过。请您从刚开始不舒服说起，疼痛后来有什么变化？
```

然后点击“发送问诊”。

这一轮主要观察：

- 学生完成自我介绍并说明问诊目的；
- 用开放式问题让患者先讲述病程；
- 患者应提到约 24 小时前起病，最初为上腹部隐痛，后来转移到右下腹；
- 患者回复旁应显示情绪标签；未识别到明显情绪时也应显示“平静”；
- 患者回复旁应有语音播放按钮，可试听一次，但不必每轮都播放。

### 第 2 轮：疼痛部位、性质、程度和加重因素

在患者回答后填写：

```text
现在主要是哪里疼？是一直胀痛，还是一阵阵绞痛？走路或咳嗽时会不会更明显？如果 0 分是不痛、10 分是最痛，现在大约几分？
```

预期获得的关键信息：

- 疼痛目前固定在右下腹；
- 呈持续性胀痛；
- 行走时加重；
- 疼痛约 6/10 分。

### 第 3 轮：伴随症状和关键阴性症状

填写：

```text
除了腹痛，有没有恶心、呕吐、发热或腹泻？小便时有没有尿频、尿急、疼痛或者看到血尿？
```

预期获得的关键信息：

- 有恶心，但没有呕吐；
- 有低热，约 37.8 ℃；
- 没有明显腹泻；
- 没有尿频、尿急或肉眼血尿。

这一轮不是为了机械凑问诊项，而是为后面的胃肠炎和输尿管结石鉴别预先收集排除证据。

### 第 4 轮：既往史和症状对生活的影响

填写：

```text
以前有过类似腹痛吗？平时有没有慢性病，做过腹部手术吗？这次疼痛对上课、走路或睡眠有什么影响？
```

预期获得的信息：

- 既往体健，没有相关慢性病；
- 没有腹部手术史；
- 症状已经影响走路或正常学习生活。

本轮暂不追问药物和食物过敏史。这是有意保留的一个小遗漏，便于训练结束后观察教师智能体能否把它转化为明确的下一轮动作。

### 第 5 轮：患者视角（ICE）

ICE 指患者的想法（Idea）、担忧（Concern）和期待（Expectation）。填写：

```text
您自己觉得这次可能是什么原因？现在最担心什么？希望我们这次先帮您解决什么？
```

预期患者会表达：

- 觉得可能是吃坏了东西；
- 担心需要做手术；
- 希望尽快明确原因并缓解疼痛。

此时重点观察患者回复的情绪标签。患者谈到害怕手术时，标签可能表现为“担忧”“害怕”等；具体名称可以随模型表达变化，但不能缺失。

## 四、第一次教师智能体介入：先处理患者担忧

患者表达害怕手术后，先不要立刻继续申请检查，点击“请求提示”。

合理的教师提示应该引导学生：

- 先回应患者情绪；
- 用一句话总结已经获得的病史；
- 解释下一步为什么需要查体；
- 获得患者同意后再操作。

提示不应直接说“答案是急性阑尾炎”，也不应替学生生成整段最终诊断。

阅读提示后，在问诊框填写：

```text
我能理解您担心需要手术。我们会先把原因一步步判断清楚，也会尽量减轻您的不适。根据您刚才说的，疼痛先在上腹部，后来转到右下腹，并伴有恶心和低热，对吗？接下来我想先测量体温并做腹部查体，会注意遮挡和隐私；如果疼得厉害请随时告诉我，可以吗？
```

这段话同时完成：

- 共情和支持性表达；
- 复述患者视角；
- 病史小结与核对；
- 说明下一步目的；
- 隐私和舒适度保护；
- 查体前知情同意；
- 共同决策式表达。

等待患者确认后再进入查体。

## 五、高级模式申请查体

在页面底部“输入想申请的查体或检查”中填写：

```text
测量体温；进行腹部视诊；检查右下腹 McBurney 点压痛、反跳痛和肌紧张，并检查 Rovsing 征。
```

点击“提交申请”，解析完成后再点击“查看申请内容”。

应重点核对以下结果：

| 申请项目 | 预期结果 | 对推理的意义 |
| --- | --- | --- |
| 体温 | 37.8 ℃ | 支持存在炎症反应 |
| 腹部视诊 | 腹平坦、无胃肠型、腹部呼吸运动减弱 | 支持局部腹膜受刺激 |
| McBurney 点压痛 | 右下腹明显压痛 | 阑尾炎关键定位体征 |
| 反跳痛 | 右下腹阳性 | 提示腹膜刺激征 |
| 肌紧张 | 右下腹轻度肌紧张 | 补充局部腹膜刺激证据 |
| Rovsing 征 | 阳性 | 进一步支持阑尾区域刺激 |

如果某一项出现在“未识别项目”中，不要连续盲点提交。先打开“查看申请内容”核对系统实际识别了什么，再把未识别的项目单独用更明确的名称申请一次。

## 六、解释检查目的并申请辅助检查

先在问诊框向患者解释，不要直接无说明地下检查。在问诊框填写：

```text
查体提示右下腹有比较明确的局限性压痛和腹膜刺激征。为了判断是否存在炎症、观察阑尾，并排除泌尿系结石，我建议查血常规、C 反应蛋白、腹部超声和尿常规。您是否理解这些检查的目的？有没有顾虑，愿意接受吗？
```

患者确认后，在高级模式申请框填写：

```text
申请血常规、C 反应蛋白、腹部超声和尿常规。
```

点击“提交申请”，再点击“查看申请内容”。

应重点核对：

| 检查 | 预期结果 | 对推理的意义 |
| --- | --- | --- |
| 血常规 | 白细胞 14.2×10^9/L，中性粒细胞 85% | 支持急性细菌性炎症 |
| C 反应蛋白 | CRP 48 mg/L | 支持炎症活动 |
| 腹部超声 | 右下腹管状低回声结构，直径 9 mm，周围少量渗出 | 直接支持阑尾炎性改变 |
| 尿常规 | 阴性，未见血尿 | 减弱右侧输尿管结石可能性 |

本轮不申请腹部 CT。现有病史、腹膜刺激征、炎症指标和超声已能组成较完整的证据链，继续堆叠检查不利于展示有目的的临床决策。

## 七、第二次教师智能体介入：把资料组织成证据链

检查结果返回后，再点击一次“请求提示”。因为问诊、查体和检查上下文已经发生变化，此时教师智能体应关注诊断综合，而不是重复第一次的沟通建议。

合理提示应推动学生回答三个问题：

1. 哪些证据共同支持当前最可能诊断？
2. 哪些阴性证据可以削弱其他诊断？
3. 还有哪一类鉴别或病史没有覆盖完整？

学生阅读提示后，在问诊框填写一段面向患者的阶段性说明：

```text
目前病史、查体和检查都提示右下腹存在急性炎症。尿常规没有血尿，所以不太支持输尿管结石；您没有明显腹泻，而且疼痛是从上腹转移后固定在右下腹，也不太像单纯胃肠炎。最终判断还需要结合全部资料。您对目前检查结果和我们的判断还有哪里不清楚吗？
```

这一步用于展示学生能把证据转化为患者听得懂的解释，并再次确认患者是否理解，而不是只在最终表单里堆医学术语。

## 八、填写“提交诊断与推理”表单

点击右侧“提交诊断与推理”。以下内容可直接作为本轮填写范例。

### 1. 当前最可能诊断（必填）

```text
急性阑尾炎
```

只写当前最支持的主诊断，不要把所有鉴别诊断都塞在这里。

### 2. 其他可能诊断（选填）

```text
右侧输尿管结石，急性胃肠炎
```

本轮暂不填写克罗恩病回盲部受累。这会留下一个真实但不影响主线的鉴别诊断缺口，供教师智能体在报告中指出。

### 3. 支持依据（必填）

```text
患者 24 小时前出现上腹部隐痛，约 8 小时前疼痛转移并固定于右下腹，现为持续性胀痛，行走加重，伴恶心和低热。查体体温 37.8 ℃，腹部呼吸运动减弱，McBurney 点明显压痛，右下腹反跳痛阳性并有轻度肌紧张。血常规示白细胞 14.2×10^9/L、中性粒细胞 85%，CRP 48 mg/L；腹部超声示右下腹管状低回声结构直径 9 mm，周围少量渗出。病史、腹膜刺激征、炎症指标和超声形成相互一致的证据链。
```

写法要点：按“病史 → 查体 → 实验室 → 影像”的顺序组织，而不是只写“检查支持阑尾炎”。

### 4. 鉴别与排除（必填）

```text
右侧输尿管结石也可表现为右侧腹痛，但本例无典型腰腹部绞痛和尿路刺激症状，尿常规阴性且未见血尿，目前不支持。急性胃肠炎通常以呕吐、腹泻或弥漫性腹痛为主，本例无明显腹泻，且疼痛由上腹转移后固定于右下腹，因此不支持单纯胃肠炎。
```

写法要点：每个鉴别诊断都要有“为什么想到它”和“本例为什么不支持它”，不能只列疾病名称。

### 5. 下一步验证计划（高级模式必填）

```text
如果继续训练，我会先补问药物和食物过敏史，并进一步核对是否存在长期反复腹痛、慢性腹泻或体重下降等病史；如果新线索与当前判断冲突，再选择有针对性的进一步影像检查，而不是无目的地重复检查。
```

这个字段填写“当前还缺什么、下一步最值得补什么”，不要写空泛的“建议完善相关检查”。

### 6. 证据不足或不确定点（选填）

```text
目前急性阑尾炎的支持证据较强，但本轮没有完整询问过敏史，对慢性炎症性肠病相关病史的采集也不够系统；这两点仍需要补齐。
```

这个字段不是自我否定，而是展示学生知道当前结论的边界。

### 7. 提交

检查六个字段后点击“提交诊断”。按钮会显示“生成报告中”，随后自动进入评分报告页。提交后本轮训练结束，不能继续追加问诊；如需补练，应重新开始新一轮训练。

## 九、训练报告应该怎么查看

报告不要只看总分。建议按下面顺序展开，每一部分都对应教师智能体的不同作用。

### 1. 总览和维度得分

先看总分及问诊、查体、辅助检查、主诊断、鉴别诊断、推理、人文沟通等维度。

本轮不应追求固定分数，因为患者表达和模型分析存在合理波动。更重要的是确认：

- 主诊断命中；
- 转移性右下腹痛、McBurney 点压痛、反跳痛、炎症指标和超声被识别为核心支持证据；
- 尿常规阴性和无腹泻被用于鉴别排除；
- 过敏史和慢性炎症性肠病鉴别被识别为仍需补强的部分。

### 2. 展开“教师复盘”

“教师复盘”默认折叠，需要手动展开。重点查看：

- “总体判断”：用较短文字概括本轮临床思路是否成立；
- “TeacherAgent 分析”：说明教师智能体基于本轮材料推测学生的思维模式，只用于复盘和训练记忆，不直接参与规则评分；
- “老师带你重走一遍临床思路”：按关键节点解释为什么这样判断、下一步该做什么；
- “本轮可以保留的做法”：应保留开放式开场、转移性疼痛追问、检查前解释、患者担忧回应、证据链组织等具体行为；
- “老师指出的问题”：不能只写“问诊不全面”，应明确到“未追问过敏史”“克罗恩病相关慢性病程线索不足”等，并解释为什么重要；
- “推理链点评”和“下一轮练习步骤”：应把问题转化为下一轮可执行动作。

有用的教师反馈示例应类似：

```text
你已经能用转移性右下腹痛、局限性腹膜刺激征、炎症指标和超声组成主要诊断证据链；下一轮不要重复堆检查，先补齐过敏史，并在右下腹痛鉴别中主动询问慢性腹泻、体重下降和反复发作等线索。
```

下面这种反馈不合格：

```text
总体表现良好，建议继续努力，完善问诊，加强临床思维。
```

后者没有指出证据、问题、原因和下一步动作，不能用于训练。

### 3. 查看临床推理轨迹

重点看学生是按什么顺序获得线索、何时形成诊断倾向，以及证据链在哪里出现断点。理想轨迹应能反映：

```text
开放问诊 → 明确转移性右下腹痛 → 收集伴随与阴性症状 → 回应患者担忧 → 有目的地查体 → 有目的地申请检查 → 组织支持和排除证据 → 提交诊断
```

如果报告只复述最后答案，不能反映上述过程，就没有充分体现教师智能体的作用。

### 4. 查看个人训练 Skill 和下一病例建议

个人训练 Skill 是从本轮可重复的问题中提炼出的训练策略，不是新的医学事实，也不替代评分。合理候选方向包括：

- 急腹症问诊收尾时固定补查过敏史；
- 右下腹痛鉴别采用“急性外科—泌尿系—消化道慢性炎症”三类框架；
- 先用病史和低成本检查缩小范围，再决定是否追加影像。

下一病例建议应和本轮暴露的问题有关，而不是随机推荐病例。进入学习画像后，还应能看到本次训练记录、薄弱方向和后续任务。

### 5. 查看评分依据与来源

最后展开来源区，确认关键点评可以追溯到病例事实、Rubric（评分量表）、本轮问诊/查体/检查证据或教学知识来源。

演示时可以这样解释：

> 规则和结构化证据负责回答“学生做了什么、覆盖了哪些评分点”；教师智能体负责回答“这些表现说明学生怎么想、问题为什么重要、下一轮应该怎么练”。教师智能体不越权修改标准答案，也不凭空创造患者事实。

## 十、这份脚本覆盖了什么，又故意没覆盖什么

### 已覆盖的核心点

- 起病时间、疼痛转移、部位、性质、程度和加重因素；
- 恶心、呕吐、发热、腹泻、泌尿系统症状；
- 既往病史和腹部手术史；
- 患者对疾病的想法、担忧、期望和生活影响；
- 自我介绍、开放问诊、阶段小结、理解确认；
- 共情、支持、隐私、知情同意和共同决策；
- 体温、腹部视诊、压痛、反跳痛及补充腹膜刺激征；
- 血常规、CRP、腹部超声、尿常规；
- 急性阑尾炎的支持证据链；
- 输尿管结石和急性胃肠炎的排除依据；
- 两个不同阶段的教师智能体过程提示；
- 训练后教师复盘、推理轨迹、个人训练策略和来源追溯。

### 有意保留的真实不足

- 问诊中没有补问药物和食物过敏史；
- 最终鉴别中没有完整提出和排除克罗恩病回盲部受累；
- 没有申请 CT 等追加检查，因为当前证据已足够，避免为“覆盖更多”而过度检查。

这样的结果更接近真实学生：主线判断成立，关键证据较完整，但仍有明确、有限、可训练的缺口。

## 十一、演示验收清单

完成后逐项确认：

- [ ] 使用的是“右下腹痛教学病例”且训练模式为“高级”；
- [ ] 学生至少完成五轮病史问诊，并完成查体前、检查前和结果解释沟通，没有把所有问题塞在一条消息里；
- [ ] 每一次患者回复都显示情绪标签；
- [ ] 患者回复可使用语音播放，失败时页面给出明确错误且不影响继续文字训练；
- [ ] 第一次教师提示围绕沟通和下一步查体，没有泄露诊断；
- [ ] 学生在查体和检查前分别解释目的并获得同意；
- [ ] 高级模式申请内容能查看，未识别项目有明确提示；
- [ ] 第二次教师提示转向证据整合，没有机械重复第一次提示；
- [ ] 最终诊断六个字段按要求填写，高级模式的“下一步验证计划”不为空；
- [ ] 报告能识别本轮做得好的具体行为和保留的真实缺口；
- [ ] 教师复盘包含“本轮表现—为什么重要—正确做法—下一轮动作”；
- [ ] 报告内容简洁具体，不是空话，也没有展开成无法执行的巨细清单；
- [ ] 关键评价可以追溯到病例、Rubric 和本轮训练证据；
- [ ] 学习画像或个人训练 Skill 能承接本轮问题，形成下一轮训练任务。
