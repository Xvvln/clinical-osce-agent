# 数据来源说明

## 已接入或已登记的数据 / 参考源

### 1. Fareez OSCE 数据集
- 来源：Figshare / Scientific Data
- 本地策略：下载原始 `Data.zip` 到 `data/raw/fareez_osce/`
- 用途：问诊语料风格、话轮结构、症状采集模式参考
- 许可：CC BY 4.0

### 2. MediTOD
- 来源：GitHub 公共仓库
- 本地策略：克隆到 `references/MediTOD/`
- 用途：意图识别、槽位抽取、对话标注结构参考
- 限制：canonicalized 数据需要 UMLS 许可和额外申请，不自动下载

### 3. MedCaseReasoning
- 来源：Hugging Face 公共数据集
- 本地策略：下载公开 parquet 文件到 `data/raw/medcase_reasoning/`
- 用途：诊断推理依据、鉴别诊断 reasoning point 提炼

### 4. CaseReportCollective
- 来源：Hugging Face 公共数据集
- 本地策略：下载公开 parquet 文件到 `data/raw/case_report_collective/`
- 用途：二期扩展病例来源，不直接作为 MVP 主数据

### 5. 参考工程
- `references/agent-chat-ui/`：前端交互参考
- `references/agent-service-toolkit/`：后端分层与服务结构参考
- `references/EasyMED/`：医学教育多智能体模块参考

### 6. 公开医学教学参考源
- AAFP Acute Abdominal Pain in Adults: Evaluation and Diagnosis
  - 来源：https://www.aafp.org/pubs/afp/issues/2023/0600/acute-abdominal-pain-adults.html
  - 用途：人工网页检索后改写为急腹痛问诊、查体、基础实验室和影像选择的 OSCE 教学知识条目
  - 限制：只用于教学提示、复盘 grounding 和来源追溯，不作为真实诊疗建议
- Merck Manual Professional Edition: Appendicitis
  - 来源：https://www.merckmanuals.com/professional/gastrointestinal-disorders/acute-abdomen-and-surgical-gastroenterology/appendicitis
  - 用途：人工网页检索后改写为提交后急性阑尾炎复盘和 Skill 生成参考
  - 限制：含诊断相关内容，只能用于 `post_submit_review`，不得进入提交前 Coach 标准答案提示
- NCBI Bookshelf StatPearls: Appendicitis / Acute Abdomen
  - 来源：https://www.ncbi.nlm.nih.gov/books/NBK493193/ 与 https://www.ncbi.nlm.nih.gov/books/NBK459328/
  - 用途：人工网页检索后改写为鉴别诊断证据链、急腹症危险信号和教学安全边界知识条目
  - 限制：只用于 OSCE 教学模拟、Agent grounding 和来源追溯，不替代医学教师审核或真实临床指南

## Git 提交策略

以下内容本地保留，不提交到 GitHub：

- `references/`
- `data/raw/`

这样可以避免：

1. 外部仓库嵌套导致 Git 历史混乱；
2. 大体积原始数据推高仓库体积；
3. 后续清洗与结构化结果难以区分。
