# 教师智能体实时介入决策说明

## 目标

训练中的 TeacherAgent 不再只在学生点击“请求提示”时工作。每次学生问诊、申请查体、申请辅助检查、记录假设、提交诊断或触发边界后，后端都会形成一条统一介入决策，并在需要时输出可见教练消息。

## 四种决策

| 模式 | 真实行为 | 典型场景 |
| --- | --- | --- |
| `silent` | 不输出教练消息 | 学生完成有效问诊，或已经修复患者情绪/知情同意问题 |
| `observe` | 只记录，不打断 | 首次轻度顺序问题；患者刚表达担忧，先给学生一次自主回应机会；相同提示进入冷却 |
| `hint` | 输出一条短提示 | 同一顺序问题再次出现；忽视患者担忧；查体或检查前没有可见的说明与同意；学生主动求助 |
| `block` | 输出边界重定向 | 索要标准答案或请求真实诊疗、用药、剂量等越界内容 |

## 人文沟通策略

1. 患者第一次表达担忧时只进入 `observe`，不抢在学生前面回应。
2. 学生下一步继续问诊、查体或检查而没有回应患者，进入 `hint`。
3. 相同人文提示只主动输出一次；问题未修复时进入冷却，避免连续刷屏。
4. 学生表达理解、回应担忧或追问患者视角后，将对应问题标记为已修复并恢复 `silent`。
5. 学生直接申请查体或辅助检查，而最近对话没有说明目的和征得同意的证据时，主动提醒一次；识别到同意后停止提示。

## 状态与审计

- Session 内部保存最多 120 条 `teacher_decision_records`。
- 每条记录包含决策时间、动作类型、模式、触发原因、问题标识、是否输出提示、修复的问题、Skill、资料来源和处理状态。
- `agent_decision_traced` 训练事件同时保存最新教学状态和最新实时介入决策。
- 学生端只获得安全投影：模式、触发类型和已经可见的提示文本，不暴露内部病例事实或完整策略。

## 边界

- 实时介入策略只决定“是否打断、为什么打断以及提示什么”，不修改病例事实、Rubric、标准诊断或评分。
- 轻度顺序问题采用“首次观察、重复提示”，避免把训练变成不断弹提示的导航工具。
- 高价值人文问题可以主动介入，但仍保留一次让学生自主修复的机会。
