# 安全边界说明

本项目仅用于医学教育模拟训练，不用于真实疾病诊断、治疗决策、用药指导或急救处置。

## 明确拒答场景

- 真实症状咨询
- 具体用药剂量
- 真实急症处置
- 要求系统替代医生作出真实诊断

## 系统原则

1. 状态优先，不做普通医学问答机器人。
2. 病例标准事实只来自结构化病例库；高级模式的 AI 模拟结果必须显式标注，不能成为标准事实或评分证据。
3. 自我进化只改教学策略，不改医学事实。

## 学生活动会话的数据边界

学生端活动会话使用 `student_session.v2` 响应投影，服务端内部状态与学生可见 JSON 分离：

- 问诊只返回本轮及此前已揭示的事实；未揭示事实、标准答案和完整病例覆盖图不下发。
- 查体与辅助检查只通过 `collected_procedure_results` 返回学生已经申请的结果；未申请结果不进入响应。
- 初级模式的快捷项只含代码、名称和必要的成本/侵入性信息，不含诊断作用、排除方向或结果；中级、高级不下发病例特定快捷项。
- 训练进度只含计数、已揭示项目和安全的下一步提示，不含 pending/must ID、Rubric 映射或完整覆盖状态。
- Skill 选择依据、RAG 原文、教学策略内部状态、决策轨迹和审计时间线只保留在服务端或提交后的受控报告链路中。

前端隐藏按钮不是权限边界。教师或管理员若需要查看完整覆盖图，应通过独立且经过角色校验的管理端接口获取，不能复用学生会话响应。

## 活动训练过程边界

- 自由文本查体 / 检查申请只在高级模式开放；初级使用病例安全快捷项，中级使用通用目录。
- 病例已配置项目直接返回结构化病例结果。高级模式中，合理但未配置的查体、辅助检查或生命体征申请可进入受控 AI 模拟链路；患者身份资料、答案、治疗处置和无法稳定识别的请求不得生成。
- 高级结果模拟是提交前最小披露原则的受控例外：生成与审核 provider 只接收脱敏、有数量和字节上限的病例临床依据、已配置所见及 `pre_submit_safe` 教学片段；不得接收病例 ID、诊断字段、Rubric、内部事实 ID、来源内部标识或完整服务端状态。
- 需要审批的模型输出只有在审批明确通过后才能进入受控链路；超时、异常、空响应或无法确认审批状态时一律 fail-closed（失败关闭），不得展示或写入活动会话。
- 模拟结果必须经过诊断 / 处置词本地门禁和病例一致性审核，在学生界面显式标注“AI 模拟、训练参考、不进入评分”，并留下服务端审计；同一项目恢复会话时复用已审核结果，不重复漂移生成。
- 评分只接受病例中已配置、由学生实际申请并获得的证据。AI 模拟结果、审批失败内容和外部知识检索结果均不能成为评分证据，也不能写回病例标准事实。

该能力用于补足高级模式自由探索，不代表真实医疗检查，也不能承诺医学上的确定性。正式教学使用前仍需医学教师审核病例、生成边界与抽样结果。

## 三角色 Skill 投影边界

- PatientAgent 只接收人文类 Skill 对应的去标识化 `practice_focus`，不接收 Skill ID、原始教学策略、Rubric 或内部触发条件。该投影只能影响语气、对总结 / 同意行为的自然回应和已存在情绪的可感知度，不能选择或新增事实。
- 临床推理、检查策略等非人文 Skill 不进入 PatientAgent。患者当前情绪仍必须来自 `patient_affect_state` 和本轮已授权事实，不得为了完成 Skill 而虚构。
- TeacherAgent 只接收 Skill Router 本轮选中的结构化教学投影。优先级固定为：病例事实边界 → 当前提示策略 → 安全边界 → 已路由 Skill 干预。Router 本轮不选择时，TeacherAgent 不得编造训练重点。
- ApprovalAgent 必须检查 `prohibited_content_policy` 和 `success_metrics`。候选显式弱化隐藏事实、标准诊断、检查结果、治疗或剂量禁区，或缺少既定成效指标时，质量复核标记为失败，回归门禁不允许自动应用。
- ApprovalAgent 是人工审批和自动应用共用的前置门禁。自动应用关闭时，候选仍必须先完成安全净化、教学结构重建、知识权限过滤和回归检查，才能进入人工待审。
- `candidate_id`、病例 / 阶段 / 触发条件、来源统计、来源引用、禁区策略和成效指标是保护字段；审批 Agent 只能修订教学表达和结构。保护字段本身出现病例答案、隐藏事实或越界内容时，系统保留原值用于审计并阻断候选，不静默改写来源事实。
- 候选进入 enabled Skill 库前再做一次 fail-closed 激活检查：人工 / 自动批准、回归通过、审批 Agent 身份、质量复核、角色禁区和上下文安全必须同时通过。直接调用候选库或 Skill 存储也不能绕过该检查。
- 老版候选的策略字段为空时，审批链路使用平台标准禁区与成效指标作为有效默认值；候选明确提供了不完整或矛盾策略时则不使用默认值掩盖问题。
